# Hardware directory

Recovered Verilog source, the original Quartus project files, and the PDF code listings are organized in this directory.

- `verilog/uart_rx/`: UART receiver modules.
- `verilog/uart_tx/`: UART transmitter modules and boot-string wrapper.
- `verilog/fifo/`: FIFO buffer.
- `quartus/`: original `.qpf` and `.qsf` project files.
- `source_documents/verilog/`: original PDF listings used to recover the HDL.
- `evidence/`: FPGA resource reports and pin-planner capture.

See [../docs/hardware_design.md](../docs/hardware_design.md) for module descriptions and known integration limitations.
